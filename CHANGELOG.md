# Changelog

## 0.1.0 - 2026-09-21

### Added

- Stateless Streamable HTTP MCP Worker with bearer authentication.
- Per-account Durable Object coordination and leases.
- Human note login through Browser Run Live View.
- Versioned AES-256-GCM profile storage in R2.
- D1 account, task, idempotency, and audit schema.
- Safe note draft creation without publication.
